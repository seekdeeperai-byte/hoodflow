HoodFlow API

JSON API for the HoodFlow token-intelligence app. There is no UI here.

  • GET /liveness — is the process responding
  • GET /readiness — this instance's own wiring state
  • GET /healthz — legacy health check
  • GET /v1/report/:chainId/:address — full token report
  • GET /v1/pulse/:chainId — ecosystem pulse

Requests are rate limited per client IP. Responses are never cached.
